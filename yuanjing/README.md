# 元境 · 生辰星图

在线体验：[https://960668.github.io/yuanjing/](https://960668.github.io/yuanjing/)

本目录是元境的完整静态网站，发布在现有 GitHub Pages 主页的独立 `/yuanjing/` 路径。

## 功能

- 输入公历生日、当地时间、UTC 偏移与可选传统排盘性别。
- 展示四柱、透干与藏干十神、八字表层五行计数。
- 支持 51 种常用神煞，重复项按柱位保留，并提供完整清单。
- 固定二维盘坐灵体；透干、藏干各一条三维轨道，神煞沿两条不共面轨道自动环绕。
- 拖拽旋转星环，滚轮或双指缩放，点击星符查看来源；出生太阳系星图与命盘 JSON 导出。

## 本地预览

下载仓库后进入本目录，运行 `python3 -m http.server 4173`，打开 `http://localhost:4173`。不要直接双击 HTML：三维脚本使用 ES modules。文件齐全后可断网预览，无需安装网页依赖。

## 更新与部署

更新此目录的文件并提交到 `main`，现有 GitHub Pages 工作流会自动重新发布。所有资源使用相对路径。

## 计算口径与隐私

生辰只在浏览器内存中计算，应用没有上传生辰的接口或应用级追踪代码；访问网站本身会请求 GitHub 的托管服务。

四柱采用 lunar-javascript 的节气与默认子时换日规则，不校正真太阳时。神煞为 51 种常用规则，非问真官方算法，尚未与问真逐项对齐；未指定传统排盘性别时不计算元辰。行星使用 NASA/JPL 1800–2050 年开普勒近似模型，地球以地月质心代替；显示距离压缩、大小不按比例。星环运动为艺术动画，不改变命盘与出生时刻。
